# Programação para Internet — Atividade de Produtos

Repositório acadêmico criado para uma atividade da disciplina de Programação para Internet.

## Objetivo da atividade

Praticar conceitos de aplicações web envolvendo:

- cookies
- sessão
- formulários
- cadastro de produtos
- fluxo de autenticação

## Estado do repositório

O branch atual contém apenas o registro/descrição da atividade e não possui a implementação completa versionada.

Este repositório é mantido como histórico acadêmico, não como projeto de portfólio principal.
